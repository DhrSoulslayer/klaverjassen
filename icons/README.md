# App Icons

Voor de PWA functionaliteit zijn de volgende icon bestanden nodig:

## Vereiste Icons

- `icon-192.png` - 192x192 pixels (voor Android en kleinere apparaten)
- `icon-512.png` - 512x512 pixels (voor iOS en grotere apparaten)

## Icon Specificaties

- **Formaat**: PNG met transparante achtergrond
- **Stijl**: Moderne, flat design met de kleuren van de app (#2c5530, #4a7c59)
- **Inhoud**: Kaartspel thema (bijvoorbeeld: ♠️♣️♥️♦️ of een gestileerde "K")

## Icon Generatie

Je kunt de icons genereren met online tools zoals:
- [Favicon.io](https://favicon.io/)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [PWA Builder](https://www.pwabuilder.com/imageGenerator)

Of maak ze zelf in een grafisch programma zoals:
- Figma
- Adobe Illustrator
- GIMP
- Canva

## Plaatsing

Plaats de icon bestanden in de root van het project (zelfde niveau als index.html).
